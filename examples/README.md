These choices are validated and remembered, not guaranteed exact product matches.

The common-period table uses each comparison's latest shared month; latest market cards keep each market's latest available period. Aligning dates does not make national baskets or categories identical: the briefs add a basket note when a comparison mixes food indices that include restaurant meals (StatCan, ABS) with one that does not (Eurostat).

**Verification scope:** the offline command checks that saved rows reproduce market means, counts, benchmarks, cost comparisons, common-period alignment and recorded SKU price arithmetic. It preserves Japan as unsupported in example 04: two markets requested, one verified. Example 06 has no pricing evidence and verifies no SKUs. Verification does not authenticate the agency/database response, replay the source index-to-YoY decoder, assess product-category fit, or prove the full meaning of model prose. Consistent changes to both rows and results can still pass. Numeric checks are not a guarantee of complete semantic correctness.
