# Recorded runs — 27 Oct 2026 (KST)

These six consecutive runs include the historical-benchmark and cost-share method, explicit comparison-category handling, calendar-based ABS/StatCan YoY decoders, common-period comparison and sentence-boundary parsing correction. They ran against Zetaris in Docker, NVIDIA Nemotron 3.5 Lightning through Meterless Nightshift, and a fresh H-MEM store. The first run also used a fresh Zetaris suffix, `night1027c11`; later runs reused what earlier runs left behind. This was a new set of application tables and views, not an empty Zetaris installation.

Each folder contains the actual `brief.md`, `trace.json` (model and agent events plus SQL statements, row counts and timings), and `recording.json` (UTC recording time, CLI elapsed seconds, exit code and namespace). Raw briefs and traces are not edited to improve their outcomes. Timing includes CLI startup; “numbers” is the agent's measured time to the first market result. Traces do not retain raw observation rows, so the stored averages and common-period values cannot be independently recomputed from these artifacts alone.

Example 01 shows successful model selection: German gochujang uses the condiment series; German chips use a broader Food proxy; Australian condiments and snacks use their selected series; Canadian narrow categories use broader Food proxies. These choices are validated and remembered, not guaranteed exact product matches. The Canadian adapter only supports Food and All-items vectors. A supported request category such as snacks can therefore have broader Food evidence.

The common-period table uses August 2026 for the DE/CA/AU and CA/AU comparisons, and September 2026 for FR/IT/ES. Latest market cards keep each market's latest available period. Aligning dates does not make national baskets or categories identical.

**Narrative limitation:** example 03 says “With a 60% cost pass-through applied”. That wording can imply the policy scales the market comparison, which it does not. The displayed benchmark is unscaled, and the policy line states this explicitly. No cost target is calculated without a stated cost change and cost share. Numeric and comparison checks do not establish complete semantic correctness; this recorded sentence is retained unchanged.

Historical benchmarks describe the latest YoY rate and recent one-year mean; they are not recommended prices, forecasts or confidence intervals. The price list is illustrative data for a fictional exporter. The earlier mixed food/snacks and policy-scaled recordings remain in Git history and local recording backups; they are not the current method.

To make a new recording, run `bash scripts/15_examples.sh`. It generates a new memory directory and Zetaris suffix by default. If overriding them, choose unused names. It refuses an existing memory directory, requires all six successful exits and complete artifacts before replacing these folders, and keeps previous recordings and logs under `logs/`.
